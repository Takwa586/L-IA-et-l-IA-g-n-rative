# L'IA et l'IA générative
Pour qu'on soit bien d'accord dés le début et ne pas se perdre, il faut qu'on donne une définition de l'IA et l'IA générative:
 *IA:(intelligence artificielle) c'est un domaine qui cherche à concevoir des systèmes capables d'accomplir des taches associées à des capacités intelligentes.
 *IA générative: c'est un système capable de générer de nouveaux contenus à partir d'une instruction et/ou d'un contexte
Quelques mots clés:
 *Machine Learning (ML):faire apprendre aux systèmes à partir de données pour prédire ou classer.
 *Deep Learning (DL):technique avancée basée sur des réseaux de neurones artificiels à plusieurs couches.
 *Large Language Model (LLM):modèle linguistique de grande taille capable de comprendre et générer du texte.
 *Prompt précis: instruction claire contenant le rôle, le public cible, le format et les contraintes.
 *Hallucination: une réponse fausse ou inventée par l'IA présentées avec assurances.
 *Biais: données d'entrainement déséquilibrées favorisant un groupe par rapport à un autre.
